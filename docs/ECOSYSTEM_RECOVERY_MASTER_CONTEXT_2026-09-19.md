## Mandatory pre-build check

Any future agent about to invent/build a new core mechanism must answer:

1. What exact problem are we solving?
2. Which Library files already discuss it?
3. Which GitHub repos already contain adjacent mechanisms?
4. Which current authority files were checked?
5. What existing primitive is closest?
6. Is the candidate a reuse, wrapper, recombination, or genuinely missing gap?
7. Why can’t the existing mechanism satisfy the target?
8. What proof will establish that the new piece is actually needed?

If these questions have not been answered, **do not build yet**.
