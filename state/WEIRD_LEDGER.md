# Weird Ledger

Save unexpected behavior that may be useful later.

Weird is not automatically a defect and not automatically a feature. It is preserved evidence for future Artifact Salvage.

## Template

### WEIRD
Short memorable name.

- **OBSERVED:** What happened that was unexpected.
- **WHY WEIRD:** Why it did not fit the intended path.
- **ORIGIN:** Project / repo / run / context where it appeared.
- **POTENTIAL SALVAGE:** What mechanism, behavior, style, side effect, combination, or idea might be reusable later.
- **PRESERVE:** YES / NO / UNTIL <condition>
- **LINKED INCIDENT:** Incident name if relevant, otherwise NONE.
- **NOTES:** Anything needed to recognize it later.

### WEIRD
Legacy guide overrode the new Loop Deck landing surface

- **OBSERVED:** The old START HERE guide won the startup race after the new simple PERFORM shell had already opened.
- **WHY WEIRD:** A legacy module behaved like an accidental post-start router and demonstrated that late-loading UI modules can override the intended shell.
- **ORIGIN:** TWIS LOOP DECK Android release run.
- **POTENTIAL SALVAGE:** Could become a deliberate mode-router, recovery/fallback screen, onboarding overlay, or startup arbitration test pattern.
- **PRESERVE:** YES
- **LINKED INCIDENT:** Loop Deck looked done but phone showed old UI
- **NOTES:** Preserve the mechanism concept, not the buggy forced navigation.
